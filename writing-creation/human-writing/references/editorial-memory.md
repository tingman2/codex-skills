# 用户写作偏好

这些偏好来自用户明确反馈，适用于用户的 AI、产品、行业与商业长文；当前任务的具体要求优先。

- 语气轻松、接地气、有趣，读后最好留得住一个具体画面或包袱。避免无必要的深沉、口号和空泛总结。
- 标题钩子从文章里真实发生的动作、反差或后果里找。备选标题要换角度，不只替换形容词。
- 用真实案例和具体步骤解释技术与商业，不把演示、公司自报或个别结果泛化。
- 幽默贴着事件本身的荒唐、返工、账单、工具表现和实际后果走。不编造亲历、对白、动机或现场细节。
- 可参考用户指定的视频所呈现的轻快拆解方式：[抖音「珍妮丁丁说」《爆笑解析OpenAI智能体越狱事件！堪比魔幻科技大片！》](https://v.douyin.com/JysFVrn3lYI/)，发布于 2026-10-03。用户喜欢它从反常动作切入，像复盘小剧情一样逐步加码，最后用评论区接梗作轻巧彩蛋。视频自动生成的章节摘要和戏剧化表达只用于学习叙事节奏，不作为事实来源；不复制创作者的标志性措辞、段式、动画桥段或口头禅。
- 用户偏好的彩蛋示例：评论者向未来的 AI 表忠心，作者回说自己现在对 Agent 客客气气，给自己“留点后路”。写新稿时应寻找该事件自己的真实尾钩，不重复借用此句。
- 对新闻或产品事实回到一手来源核验；区分测试、疑似行为、确认行为与实际损害。保留轻松语气，不牺牲准确性。
